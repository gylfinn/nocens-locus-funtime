# Nocens Locus Funtime

1. Drop an export named `<guide>!<BattleTag>.txt`; the source BattleTag is read from the name.
2. Tick the destination BattleTags (saved in this browser) and click.
3. Download one `<guide>!<BattleTag>.txt` per ticked BattleTag.

Only the RC4 layer changes, so each file keeps the original's compressed data, header and size.


## Run

```bash
pnpm install
pnpm dev
```
